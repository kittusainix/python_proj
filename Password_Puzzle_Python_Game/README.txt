PASSWORD PUZZLE - PYTHON MINI PROJECT

ABOUT
A small password/code guessing game. The game chooses a random 4-digit code.
You have 8 attempts to guess it. After each guess, it tells you how many digits
are in the correct position and how many are correct but in the wrong position.

HOW TO RUN ON WINDOWS
1. Extract the ZIP file.
2. Open the extracted folder.
3. Open the folder address bar, type cmd, and press Enter.
4. Run:
   python password_puzzle.py
   or:
   py password_puzzle.py

HOW TO PLAY
- Enter exactly four digits (example: 1234).
- Click Check Code, or press Enter.
- Use the hints to solve the secret code.
- Click New Game to play again.

REQUIREMENTS
- Python 3
- Tkinter (usually included with Python on Windows)
- No extra packages required.

NOTE
This is an educational guessing game, not a real password-cracking tool.
